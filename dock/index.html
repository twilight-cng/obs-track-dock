トラックの使い方

  1. OBS の音声はトラック 1〜6 です。表の列がそのまま対応します。
  2. チェックを入れると、そのソースの音がそのトラックに載ります。外すと、そのトラックには乗りません。
  3. 列の名前は「設定」で変えられます。初期値は 1=配信、2=録画、3〜6=トラック3〜6 です。
  4. 配信や録画ファイルにどのトラックを含めるかは、OBS の出力設定で決まります。このドックは、ソースをどのトラックへ乗せるかを切り替えます。
  5. ソース名に BGM が含まれるときの目安は、名前が「配信」または stream の列は ON、「録画」「record」「vod」の列は OFF です。違うと行が警告色になります。
  6. ソースを追加した直後は、配信のみ / 録画のみ / 両方 / すべてOFF から選べます。
