# OBS Track Dock

OBS のオーディオトラック（1〜5）を、わかりやすい表示名でトグル操作する **カスタムブラウザドック** です。ネイティブプラグインではなく、`dock/` にある HTML / CSS / JavaScript を OBS のカスタムブラウザドックから開きます。

## できること

- トラック 1〜5 に「配信」「録画」などの表示名を付けられる
- ソースごとのトラックをトグルで ON/OFF する
- 名前に `BGM` を含むソースを検知し、配信 ON・録画 OFF でなければ警告する
- ソース追加時にトラック選択ダイアログを出す（プリセット: 配信のみ / 録画のみ / 両方 / すべてOFF）

## 導入方法

### 要件

リポジトリから確認できるものは次のとおりです。

- **形態**: OBS 用のカスタムブラウザドック。`dock/index.html`、`dock/app.js`、`dock/style.css` の 3 ファイルだけです。プラグイン用バイナリ、インストーラ、`package.json`、ビルドスクリプト、CI（`.github/workflows` など）は含まれていません。
- **OBS**: 既存の記載どおり **OBS 28 以降**（obs-websocket 5）向けです。接続実装は obs-websocket 5 の RPC（`rpcVersion: 1`、WebSocket の `op` 0 / 1 / 2 / 5 / 6 / 7）です。
- **OBS 側の機能**: WebSocket サーバーと、カスタムブラウザドック。
- **実行時の依存パッケージ**: ありません。ブラウザ側の API（WebSocket、`localStorage`、`crypto.subtle`、ES modules、`<dialog>`）だけで動きます。
- **既定の接続先**: ホスト `127.0.0.1`、ポート `4455`、パスワードは空文字。トラック表示名の初期値は `配信`、`録画`、`トラック3`、`トラック4`、`トラック5` です。

### ドックの追加

1. OBS の **ドック → カスタムブラウザドック** を開く
2. ドック名に `Track Dock` を入れる（OBS 上の表示名です。ページ側ではこの文字列を検証しません。ページのタイトルは `OBS Track Dock` です）
3. URL に、上で決めた `dock/index.html` の URL を指定する

### 初回セットアップ

1. ドックを開くと、読み込んだ設定を `localStorage` に保存してから自動接続します。保存済みがなければ既定値（`127.0.0.1`、`4455`、空のパスワード）です。
2. 接続できないときは、ステータスが **未接続（設定を確認）** になります。
3. **設定** を開き、ホスト・ポート・パスワードと、トラック 1〜5 の表示名を入力する。
4. **保存して閉じる** を押す。ここまで押さないと、入力欄の変更は接続に使われません。
5. **接続** を押す。成功するとステータスが **接続中** になり、音声ソースの一覧を取得します。

設定の保存先は、ドックのページが使う `localStorage` のキー `obs-track-dock-v1` です。パスワードもこの JSON に平文で入ります（暗号化する処理はありません）。ホストが空なら `127.0.0.1`、ポートが数値でなければ `4455`、表示名が空ならトラック番号の文字列（`1`〜`5`）を保存します。

### `file://` で開かない場合

`file://` で動かない場合は、`dock/` フォルダを簡易 HTTP で配信し、次の形の URL をドックに指定します。

```
http://127.0.0.1:<ポート>/index.html
```

配信するディレクトリは `dock/` です。`index.html` が `./app.js` と `./style.css` を相対パスで読むためです。

## 使い方

### 画面の操作

| 表示 | 動作 |
| --- | --- |
| ステータス | 未接続、接続中…、認証中…、接続中、切断、接続失敗、またはエラー文言 |
| **接続** | `ws://<ホスト>:<ポート>` へ接続し、必要なら認証してからソース一覧を取り直す |
| **設定** | 接続とトラック表示名の入力欄を開閉する（このボタンだけでは保存しない） |
| **更新** | 接続中にソース一覧を取り直す。未接続のときは失敗する |
| 表のチェックボックス | そのソースのトラック 1〜5 を ON/OFF し、OBS へ反映する |
| 空の表 | 「音声ソースがありません。接続するか更新してください。」 |

一覧に出るのは `GetInputAudioTracks` が成功したソースだけです。失敗した入力は読み飛ばします（コメントでは、音声トラックを持たない入力を想定しています）。ソース名は日本語ロケールでソートします。

チェックを変えると `SetInputAudioTracks` を送ります。送る前に現在の `inputAudioTracks` を取得し、トラック 1〜5 だけを上書きしてマージします。実装コメントでは、トラック 6 がある場合にその値を維持する意図です。現在値の取得に失敗したときは、トラック 1〜5 だけを送ります。反映に失敗するとチェックは元に戻り、ステータスにエラーが出ます。

OBS 側のイベント `InputCreated`、`InputRemoved`、`InputNameChanged`、`InputAudioTracksChanged` も表へ反映します。購読フラグは `(1 << 0) | (1 << 3)` で、コードのコメントでは General と Inputs と書かれています。

### 新規ソース

入力が追加されると（`InputCreated` の 200 ミリ秒後にトラック取得へ成功したとき）、**新しいソースのトラック** ダイアログが開きます。取得に失敗した入力では開きません。

- **配信のみ**: 表示名が「配信」または `stream`（大文字小文字は区別しない）に一致するトラックを ON。一致がなければトラック 1 だけ ON
- **録画のみ**: 表示名が「録画」または `record` / `vod`（大文字小文字は区別しない）に一致するトラックを ON。一致がなければトラック 2 だけ ON
- **両方**: 「配信のみ」で ON になるトラックと、「録画のみ」で ON になるトラックの和集合（それぞれの名前が一致しなければ、配信側はトラック 1、録画側はトラック 2）
- **すべてOFF**: トラック 1〜5 をすべて OFF
- **適用**: ダイアログの内容を OBS に送る
- **スキップ**: 何も送らず閉じる

ソース名に `BGM`（大文字小文字不問）が含まれる場合、ダイアログを開いた時点で **配信のみ** のチェック状態になります。自動では適用されず、**適用** を押したときだけ OBS に送られます。

### BGM の警告

ソース名に `BGM`（大文字小文字不問）を含む行だけを判定します。画面の説明は「名前に BGM を含むソースは、配信ON・録画OFF が正解です。」です。

- 表示名が「録画」または `record` / `vod`（大文字小文字は区別しない）のトラックが ON のとき、警告 `BGM が「…」に乗っています`。そのチェックは警告色になる
- 上に当てはまらず、表示名が「配信」または `stream`（大文字小文字は区別しない）のトラックが 1 つ以上あり、それらがすべて OFF のとき、警告 `BGM の「…」が OFF です`
- 「配信」または `stream` の表示名が一つもないときは、配信側の OFF 警告は出さない
- 上記以外では警告文は出ません。凡例に「正常」と「BGM 警告」の色見本がありますが、「正常」は行へ付与される状態ではありません。警告がある行だけが警告表示になります

表示名を保存し直すと、開いているソースの警告も計算し直します。

インストーラ、OBS プラグインディレクトリへの配置、アンインストール用スクリプトはリポジトリにありません。利用をやめるときに消える対象は、次の 2 つです。

設定はドックページの `localStorage`（キー `obs-track-dock-v1`）に残ります。ドックを開いただけでも、その時点の設定が書き込まれます。
