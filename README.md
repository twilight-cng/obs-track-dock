# OBS Track Dock

OBS のオーディオトラック（1〜5）を、わかりやすい表示名でトグル操作する **カスタムブラウザドック** です。

## できること

- トラック 1〜5 に「配信」「録画」などの表示名を付けられる
- ソースごとのトラックをトグルで ON/OFF
- 名前に `BGM` を含むソースを検知し、配信ON・録画OFF でなければ警告
- ソース追加時にトラック選択ダイアログ（プリセット: 配信のみ / 録画のみ / 両方）

## セットアップ

1. OBS の **ツール → WebSocket サーバー設定** でサーバーを有効化（ポート 4455 など）
2. OBS の **ドック → カスタムブラウザドック**
3. ドック名: `Track Dock`
4. URL に次を指定（パスは環境に合わせて変更）:

```
file:///C:/Users/mou/Desktop/obs-track-dock/dock/index.html
```

5. ドック内の **設定** でホスト・ポート・パスワード、トラック表示名を保存
6. **接続**

## BGM ルール

- ソース名に `BGM`（大文字小文字不問）を含む
- 表示名に「配信」または `stream` があるトラック → ON が正解
- 表示名に「録画」または `record` / `vod` があるトラック → ON なら警告

## 注意

- OBS 28+（obs-websocket 5）向け
- `file://` で動かない場合は、フォルダを簡易 HTTP で開いて `http://127.0.0.1:.../index.html` を指定してください
